# Autogenesis capability catalog

Packaged baseline for Autogenesis **v0.7.0**. Usable with no Atlas mounted.
Live listing authority is the parent registry in the loaded root `SKILL.md`.
This snapshot is version-qualified packaged help, not a second router.

Capability-facing modules are parent-registry **operations** only.

| Module | Purpose |
| --- | --- |
| getting-started | First-use: purpose, prerequisites, and the shortest useful journey |
| help | Explain Autogenesis modules without executing them |
| design | Genesis, instruction-first runtime selection, challenge and persisted plan; stop for approval |
| initialise | Confirm purpose and fusion scope; design only needed runtime capabilities; stop for approval |
| implement | Apply only an explicitly approved persisted plan; evaluate and record lineage |
| research | Expand the resolved subject Atlas with sourced knowledge |
| reflect-challenge | Challenge observed behaviour without implementation authority |
| learn-skill | Record subject-owned peer usage without peer mutation |
| reevaluate | Assess material knowledge impact; advisory only |
| aware-runtime | Maintain governed runtime awareness |
| wire | Explicitly approved wiring with version provenance |
| review-package | Review the target's chosen composition and applicable conformance facets; advisory report |
| atlas-migrate | Migrate legacy storage through Atlas and preserve knowledge |

Support modules (`workflow-discipline`, `think-*`, `patterns`, `validate-*`)
are not listed here unless the parent registry marks them `operation`.

Ask Autogenesis help with `target` set to a name from this table for details.
Ask getting-started for the first-use journey. Discussion is the catalog
**discuss** package, not an Autogenesis module.
