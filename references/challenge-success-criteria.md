# Challenge-success criteria

Used at the end of path **design** after the internal think-challenge module and autonomous pin.

| ID | Criterion | Pass means |
|----|-----------|------------|
| C1 | Non-trivial counter | At least one substantive challenge written |
| C2 | Disposition of high-severity counters | Each is pinned into the plan or rejected with rationale |
| C3 | Pinned decisions visible | Plan file has a Pinned decisions section post-challenge |
| C4 | Scope integrity | Intent/boundaries not silently expanded toward implement |
| C5 | Approval hinge | No implementation performed on design path |
| C2-ext | External counter (optional) | Grounded/external challenge used when feasible |

These measure **challenge quality**, not post-implement product success.
